# HR Bank Security Awareness Training Program

## Document Control
- **Version:** 1.0
- **Effective Date:** January 28, 2026
- **Owner:** Security Team
- **Review Frequency:** Annual

---

## 1. Program Overview

### 1.1 Purpose
This Security Awareness Training Program ensures all HR Bank employees, contractors, and partners understand their security responsibilities and can identify and respond to security threats.

### 1.2 Scope
- All employees (full-time, part-time)
- Contractors with system access
- Third-party partners with data access

### 1.3 Compliance Requirements
- SOC2 Trust Service Criteria CC2.2
- PIPEDA Privacy Requirements
- Industry Best Practices

---

## 2. Training Requirements

### 2.1 Training Schedule

| Training Type | Audience | Frequency | Duration |
|--------------|----------|-----------|----------|
| New Hire Orientation | New employees | Within 7 days of start | 2 hours |
| Annual Refresher | All staff | Annually | 1 hour |
| Role-Based Training | Technical staff | Quarterly | 30 min |
| Phishing Simulations | All staff | Monthly | N/A |
| Incident Response | Security team | Quarterly | 2 hours |

### 2.2 Training Completion Requirements
- All training must be completed within required timeframe
- Minimum passing score: 80%
- Failed assessments require retake within 7 days
- Completion tracked in HR system

---

## 3. Training Modules

### Module 1: Security Fundamentals (All Staff)
**Duration:** 30 minutes

**Topics Covered:**
- Information security principles (CIA triad)
- HR Bank security policies overview
- Data classification levels
- Acceptable use policy
- Reporting security incidents

**Assessment:** 10 multiple choice questions

---

### Module 2: Password & Authentication Security (All Staff)
**Duration:** 20 minutes

**Topics Covered:**
- Password requirements and best practices
  - Minimum 8 characters
  - Complexity requirements
  - No password reuse (last 10)
- Multi-factor authentication usage
- Account lockout procedures
- What to do if credentials are compromised

**Assessment:** 10 multiple choice questions

---

### Module 3: Phishing & Social Engineering (All Staff)
**Duration:** 30 minutes

**Topics Covered:**
- Recognizing phishing emails
  - Suspicious sender addresses
  - Urgent language and threats
  - Unexpected attachments
  - Hover before clicking links
- Social engineering tactics
- Reporting suspicious communications
- Real-world examples and case studies

**Assessment:** Interactive phishing identification exercise

---

### Module 4: Data Protection & Privacy (All Staff)
**Duration:** 30 minutes

**Topics Covered:**
- PIPEDA compliance requirements
- Handling personal information
- Data classification (Restricted, Confidential, Internal, Public)
- Encryption requirements
- Secure data disposal
- Data breach notification procedures

**Assessment:** 10 multiple choice questions

---

### Module 5: Physical Security (All Staff)
**Duration:** 15 minutes

**Topics Covered:**
- Clean desk policy
- Visitor management
- Secure document disposal
- Device security (laptops, phones)
- Working from home security

**Assessment:** 5 multiple choice questions

---

### Module 6: Remote Work Security (All Staff)
**Duration:** 20 minutes

**Topics Covered:**
- Secure home network setup
- VPN usage requirements
- Public Wi-Fi risks
- Video conferencing security
- Protecting physical workspace

**Assessment:** 5 multiple choice questions

---

### Module 7: Incident Response (Technical Staff)
**Duration:** 45 minutes

**Topics Covered:**
- Incident classification (P0-P3)
- Detection and reporting procedures
- Containment strategies
- Evidence preservation
- Communication protocols
- Post-incident review

**Assessment:** Scenario-based exercise

---

### Module 8: Secure Development (Engineering Staff)
**Duration:** 60 minutes

**Topics Covered:**
- OWASP Top 10 vulnerabilities
- Secure coding practices
- Input validation
- Authentication/authorization best practices
- Secrets management
- Code review security checklist
- Dependency vulnerability scanning

**Assessment:** Code review exercise

---

## 4. Phishing Simulation Program

### 4.1 Program Structure
- Monthly simulated phishing campaigns
- Varied difficulty levels
- Multiple attack vectors (email, SMS)
- Immediate feedback on clicks

### 4.2 Metrics Tracked
- Click rate by department
- Report rate
- Repeat offenders
- Improvement trends

### 4.3 Response to Failed Simulations
| Occurrence | Action |
|------------|--------|
| First failure | Educational feedback |
| Second failure | Additional training module |
| Third failure | Manager notification |
| Fourth failure | Access review |
