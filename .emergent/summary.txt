<product_requirements>
The HR Bank is a multi-role workforce management platform for the Canadian market, connecting a Workforce, Employers, and Admins.

**Core functionality includes:**
*   **Role-Based Access:** Separate portals for each user type with role-specific features.
*   **AI Assistant (Emma):** A conversational AI to guide users, now optimized and disabled for Admin accounts to reduce irrelevance.
*   **Admin Super-Panel:** A comprehensive dashboard for system oversight.
    *   **User/Zone Management:** Tools to manage users and geographic operational zones.
    *   **Advanced Analytics:** A rich dashboard providing breakdowns of users by geographic location, top employers/workers by revenue, and real-time demand for skills and certifications.
    *   **Occupation & Certification Management:** A system to create and manage occupation templates. This has been enhanced to include a standardized, centrally managed list of required certifications based on Canadian government standards (e.g., Red Seal, Food Safety).
*   **Job Matching Engine:** Employers post jobs using the standardized occupation and certification data. The platform matches them with qualified workers. Workforce users can build profiles, add their standardized certifications, and apply for jobs. The system is designed to show qualification levels for roles.
</product_requirements>
