<product_requirements>
The HR Bank is a workforce management platform for four user roles: **Workforce**, **Employers**, **Institutions**, and **Admins**. Its core function is to connect workers with employers for shift-based work.

**Key Features Implemented:**
1.  **Role-Based Access**: Secure, distinct experiences for each user role.
2.  **Personalized Experience**: Dashboards and headers are customized with user-specific data like name, company name, photo/logo, and occupation titles.
3.  **Occupation Profiles**: Workers can create detailed profiles, styled as resume cards, showcasing experience, skills, and verified credentials.
4.  **Settings & Security**: A dedicated settings page for each user type allows editing personal information (name, address), changing passwords, and verifying contact details via OTP (phone and email). Users can also upload profile photos with a cropping tool.
5.  **Document Management**: A centralized system for users to upload and manage required documents.

**Current Requirements being implemented:**
The document system must be enhanced to:
1.  Enforce role-specific document requirements (e.g., Work Permit for Workforce, Business License for Employers).
2.  Capture issue and expiry dates for all validation-required documents.
3.  Automatically send email reminders for expiring documents and deactivate accounts if they are not updated.
</product_requirements>
