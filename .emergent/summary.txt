<product_requirements>
The primary goal is to enhance the job matching engine's accuracy by systemically linking occupations to a list of required certifications.

**Feature Breakdown:**

1.  **Employer Job Posting:** When an employer selects an occupation for a new job post, the UI must automatically fetch and pre-populate the list of certifications required for that occupation. The employer must have the ability to remove these auto-suggested certifications or add other ones.
2.  **Workforce Profile:** When a workforce user views their selected occupations, the UI should clearly indicate which certifications are required for that role and visually distinguish between certifications the user has versus those they are missing.
3.  **Matching Algorithm:** The core job matching engine must be updated to differentiate between certifications required by the occupation template and those added manually by the employer. The occupation-linked certifications are to be treated as the primary criteria, holding more weight in the matching score.
4.  **Platform Parity:** These features should be implemented across both the web application and the workforce mobile app.
</product_requirements>
